# ProjetoAPS - Análise e Projeto de Sistemas

## 📋 5W - Estrutura do Projeto

### **WHAT (O QUÊ)**
**O que é este projeto?**

ProjetoAPS é um projeto acadêmico focado na aplicação de técnicas e métodos de **Análise e Projeto de Sistemas de Informação**, com ênfase principal na **orientação a objetos**. O projeto demonstra a geração de artefatos de sistemas seguindo as melhores práticas de engenharia de software.

### **WHY (POR QUÊ)**
**Por que este projeto existe?**

Este projeto foi desenvolvido para:
- 📚 **Aprender** as técnicas fundamentais de análise e projeto de sistemas
- 🎯 **Aplicar** conceitos de orientação a objetos na prática
- 📐 **Gerar** artefatos profissionais (diagramas, documentação, modelos)
- 💡 **Demonstrar** competências em engenharia de software
- 🔍 **Compreender** o ciclo completo de desenvolvimento de sistemas

## 🎓 Objetivos Principais

✅ Aplicar técnicas de **UML** (Unified Modeling Language)  
✅ Modelar sistemas com **Orientação a Objetos**  
✅ Documentar requisitos e especificações  
✅ Gerar diagramas de caso de uso, classes e sequência  
✅ Aplicar padrões de design e boas práticas
